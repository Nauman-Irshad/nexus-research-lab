# Nauman Irshad Lab

Official website for **Nauman Irshad Lab** — student-led collaborative research in AI, cybersecurity, digital twins, computer vision and NLP at the University of Central Punjab, Lahore.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Deployed on Vercel (images and assets served via Vercel CDN)

## Scripts

```bash
npm install
npm run dev      # local (webpack on Windows)
npm run build    # production build
npm start
```

## Key routes

- `/` — home (lab info + upcoming work)
- `/upcoming` — submission-pending papers & ongoing projects
- `/portfolio` — Nauman Irshad Ali Shah portfolio
- `/people` · `/projects` · `/publications` · `/conference` · `/gallery` · `/contact`
